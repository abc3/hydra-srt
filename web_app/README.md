# HydraSRT Web App

React UI for HydraSRT.

## Development

Normally started by Phoenix:

```bash
make dev
```

Run directly when working only on the UI:

```bash
cd web_app
yarn dev
```

Default dev URL: [http://localhost:5173](http://localhost:5173).

## Tests

```bash
cd web_app
npm run test:unit
npm run test:e2e
```
